# TheWorthScout

Independent Guides & Product Reviews. Astro static website for Cloudflare Pages.

## Local development

```bash
npm install
npm run dev
npm run build
```

## Cloudflare Pages

Connect GitHub repository `ngchagas/theworthscout`. Framework preset: **Astro**; build command: `npm run build`; output directory: `dist`; production branch: `main`. Then add `theworthscout.com` under **Custom domains** in Pages. Ensure Cloudflare DNS zone is active.

## Before public launch

- Replace placeholder Contact details with a real monitored address.
- Review Privacy Policy for actual analytics, advertising, cookies and local legal requirements.
- Add original, substantiated pet content and per-article affiliate disclosures before advertising.
- Confirm affiliate-program PPC permissions and tracking before paid campaigns.
- Configure Search Console, analytics and conversion measurement.
- Review brand/trademark clearance.

No affiliate programs, tracking scripts, or fake reviews are installed.
